Glossary

Daemonloom keeps similar-looking concepts separate because they carry different authority and lifecycles.

TermMeaning
FoundationIndependently useful Identity, Connectors, and Substrate domains plus their stable contracts.
Agent layerProvider- and harness-agnostic lifecycle, tool, context, event, delegation, and cancellation contracts owned by Agent.
ProductAn opinionated customer experience composed from foundation capabilities.
PrincipalAn authenticated human or service identity with tenant context.
TenantThe organization boundary carried in admitted authority and checked by each receiver.
Agent revisionAn immutable version of behavior, knowledge, goals, budgets, and declared capabilities.
RunOne lifecycle-bound execution of one agent revision against input and an authority snapshot.
Harness adapterAn Agent integration that drives a supported external agent product interface while the harness retains its loop and protocol semantics.
Direct-provider adapterAn Agent integration that calls a documented model API while the Daemonloom runtime owns the loop.
ProviderA compiled Connector catalog template for one external system.
IntegrationA tenant's configured enablement of a provider.
ConnectionAn authorized provider instance, scoped to a tenant or principal.
Connector grantAuthority to invoke selected declared operations over selected connections. It never carries credentials.
OperationOne declared capability with a contract, risk, idempotency, effects, interaction shape, and execution requirements.
EventA declared provider-originated semantic fact delivered through the Connector lifecycle.
ChannelA supervised provider transport that delivers declared events or establishes a bounded session without requiring a client process to stay connected.
Interaction shapeThe lifecycle of a connector member: unary, stream, subscription, leased session, or session establishment.
Protocol driverA closed, catalog-selected implementation for one wire protocol, such as http_v1 or sip_v1; it is not caller-selected and does not identify the provider.
Session channelA supervised inbound transport that establishes a bounded bidirectional lifecycle instead of delivering an invented event.
VoiceSessionThe protocol-neutral semantic contract for a governed call session.
RTVBPOne local binding of VoiceSession control and media behind a voice edge; not a provider, catalog operation, or model tool.
SatelliteThe same Connectors service deployed near private endpoints and federated outward under bounded authority.
WorkspaceA Substrate-owned confined filesystem and execution context.
ExecA bounded process run inside a workspace.
WorkloadA long-lived Substrate-managed application running from an image.
AdmissionAn owner-domain decision that required authority and enforcement are available before dispatch.
EvidenceCorrelated facts about intent, revision, authority, decisions, observations, cost, and outcome; provenance remains owner-specific.
Behavior-revision promotionProduct decision that changes which evaluated agent revision is live.
Organizational promotionGuild decision that changes role, responsibility, reporting, or management scope.
Resource scalingCloud or Substrate decision that changes compute, concurrency, spend, or deployment capacity.
PosturePersonal, organization, or SaaS deployment configuration. Capabilities remain semantically consistent.
Byte planeDirect continuous terminal, tunnel, or media traffic established under governed authority but not relayed through ordinary invocation.

Behavior-revision promotion, organizational promotion, and resource scaling are independent. The same evidence may inform all three, but authority in one axis never implies authority in another.
