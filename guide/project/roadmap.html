Public roadmap

The roadmap is organized around evidence gates, not calendar promises. Detailed sequencing remains in each owner repository; this page shows how the public pieces connect.

Now: close the foundation contracts​

  • Extend Substrate from lifecycle-managed processes into durable, reconnectable daemon sessions.
  • Complete the Connectors source-tooling and platform-family prerequisites around the compiled catalog.
  • Keep Agent's model-free conformance paths green while replacing direct development execution with owner-released foundation contracts.
  • Extract Agent's reusable coding-harness engine, deterministic capability catalog, and shared session supervisor; prove a minimal terminal UI and headless projection over the same controls.
  • Close Guild's first workforce-domain invariants and publish a development contract.

Next: prove one governed vertical slice​

The first meaningful cross-project proof is deliberately narrow:

  1. bind one immutable agent revision to one tenant-scoped work request;
  2. execute through the generic Agent lifecycle;
  3. suspend on one declared external operation requiring approval;
  4. admit that operation through one Connector grant and connection;
  5. run any required process under Substrate confinement;
  6. return owner-produced observations as correlated platform evidence;
  7. cancel the same path and prove it cannot later complete.

The slice should be model-free where possible. It proves boundaries before live-provider behavior.

Then: owner releases and hosted composition​

  • Package and sign stable foundation bundles with reproducible conformance evidence.
  • Implement Identity's bounded bootstrap and receiver-verification contracts after the explicit implementation gate.
  • Implement Cloud as pinned hosted composition without moving foundation or product semantics into it.
  • Build the generic AI Agent Platform's definition, evaluation, work, evidence, and promotion loop.
  • Let downstream products adopt stable owner contracts through their own adapters.

Later capabilities​

Later work may include connector satellites near private infrastructure, direct terminal or media byte planes, native SIP/voice channels, additional provider and harness adapters, organization overlays, and richer workforce products. These directions remain subordinate to the same authority, confinement, evidence, and no-silent-fallback rules.

See current status for the maturity snapshot that constrains these next steps.
